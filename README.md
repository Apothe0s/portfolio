# Angelito’s portfolio

A Windows 11 inspired desktop portfolio built with Next.js and React. Open apps from the desktop, centered taskbar, or searchable Start menu. Windows support dragging, resizing, minimizing, maximizing, and closing. The terminal supports `help`, `whoami`, `projects`, `skills`, `contact`, and `clear`.

## Development

```sh
npm ci
npm run dev
npm run build
```

Content and project images come from the existing portfolio. Edit `src/constants/constants.js` for projects and timeline entries; other portfolio content is in `src/pages/index.js`. Project URLs that still point to the original Google placeholders are withheld until real links are supplied.
