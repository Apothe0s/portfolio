# Install the pixel profile

1. Create a **public** GitHub repository named **Apothe0s**, owned by **Apothe0s**.
2. Add the contents of this folder's `README.md` as the repository's root `README.md`.
3. Open https://github.com/Apothe0s to see the profile.

The artwork is hosted in `Apothe0s/portfolio` under `profile/`. The README uses absolute image URLs, so it works without copying the SVG files. To make the new repository self-contained, copy those assets and replace their URLs with relative paths.

The three project demos are private. Change their visibility before removing the private-access note.
